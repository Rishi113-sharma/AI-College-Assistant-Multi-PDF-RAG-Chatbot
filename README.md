**AI College Assistant — Multi-PDF RAG Chatbot**

Developed a Generative AI-powered college assistant using **LangGraph and RAG** to answer student queries from multiple college documents. Implemented an LLM-based classifier to route questions to dedicated retrieval pipelines for **academic information, fee structure, and B.Tech syllabus**, while general questions are answered directly by the LLM. Used **FAISS and Sentence Transformers** for semantic document retrieval and **Gemini** for classification and response generation. Built a **Streamlit** interface with programme selection, chat history, and separate handling of retrieved and general queries.

**Tech Stack:** Python • Generative AI • RAG • LangGraph • Gemini • LangChain • Streamlit • FAISS • Hugging Face Embeddings • Sentence Transformers • PyPDFLoader • Recursive Character Text Splitter • Prompt Engineering
